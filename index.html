How to find a Discord channel ID

  1. Open Discord settings and enable Developer Mode under Advanced.
  2. Right-click the channel your agent should use.
  3. Choose Copy Channel ID and paste it into ClawBoard setup.

Use one channel per agent for replies. The board status channel is optional and can be a shared channel such as project-updates.
